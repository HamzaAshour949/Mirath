# ميراث (Mirath)

ميراث هو تطبيق احترافي لحساب المواريث الإسلامية وفق المذاهب السنية الأربعة: الحنفي والمالكي والشافعي والحنبلي.

يستهدف المشروع العلماء والحقوقيين والموثقين ومستشاري تقسيم التركات، ويقدم نسخة مكتبية ونسخة ويب وموقعًا للتعريف والشراء، بالإضافة إلى لوحة إدارة وخادم لإدارة التراخيص.

## مكونات المشروع

- `apps/app`: التطبيق الرئيسي المبني باستخدام Tauri وReact، مع دعم سطح المكتب والأجهزة اللوحية.
- `apps/web`: نسخة الويب المبنية باستخدام React وVite، وتحتاج إلى ترخيص صالح.
- `apps/admin`: لوحة الإدارة المبنية باستخدام Next.js لإدارة التراخيص.
- `apps/marketing`: الموقع التسويقي المبني باستخدام Astro.
- `apps/license-server`: خادم تفعيل التراخيص والتحقق من إلغائها.
- `packages/core`: محرك حساب المواريث المكتوب بـ TypeScript، ويشمل الحجب والعول والرد والعصبات.
- `packages/ui`: مكونات الواجهة المشتركة والداعمة للغتين العربية والإنجليزية.
- `packages/i18n`: ملفات الترجمة العربية والإنجليزية.
- `packages/pdf`: إنشاء تقارير PDF.
- `packages/docx`: إنشاء تقارير DOCX.
- `packages/mirath-format`: ترميز وفك ترميز ملفات `.mirath`.

## المتطلبات

- Node.js
- pnpm 9
- Rust، لتطوير تطبيق Tauri

## التثبيت

```bash
pnpm install
```

## أوامر التطوير

يمكن تشغيل جميع التطبيقات من جذر المشروع باستخدام:

```bash
pnpm dev
```

ولتشغيل تطبيق محدد:

```bash
pnpm --filter @mirath/app dev
pnpm --filter @mirath/web dev
pnpm --filter @mirath/admin dev
pnpm --filter @mirath/marketing dev
pnpm --filter @mirath/license-server dev
```

تتطلب بعض الحزم أسماءً مختلفة في إعدادات `package.json`، لذلك يمكن أيضًا الدخول إلى مجلد التطبيق وتشغيل `pnpm dev` داخله.

## الاختبارات والتحقق

```bash
pnpm test
pnpm typecheck
pnpm build
```

يتضمن `packages/core` اختبارات لمحرك حساب المواريث والحالات الخاصة المرتبطة بالمذاهب.

## التراخيص والأمان

يستخدم المشروع ترخيصًا لكل جهاز. يحتفظ خادم التراخيص بالمفتاح الخاص لتوقيع ملفات الترخيص، بينما يستخدم التطبيق المفتاح العام للتحقق.

لا تضع مفاتيح التوقيع أو رموز الإدارة أو بيانات الاتصال بقواعد البيانات داخل Git. خزّنها في ملفات `.env` محلية أو في مدير أسرار مناسب. ملفات البيئة والبيانات المحلية مستبعدة من Git بحسب إعدادات المشروع.

## اللغات

يدعم المشروع العربية والإنجليزية، مع مراعاة اتجاه الكتابة من اليمين إلى اليسار في الواجهات والتقارير العربية.

## حالة المشروع

المشروع قيد التطوير، ويحتوي على تطبيقات وحزم متعددة ضمن مستودع واحد يعتمد على pnpm وTurborepo.
